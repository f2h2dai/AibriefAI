# Reviewed Lightpanda PandaScripts

Store only reviewed deterministic PandaScripts here.

- Public web sources only.
- No credentials, cookies, tokens, local storage, private URLs, form submission, downloads, or file upload.
- Use `--obey-robots` during discovery.
- Keep an equivalent Chromium fallback until the source is proven stable.
- Run scripts through `aibrief.connectors.browser_router.run_pandascript`; direct scheduled execution is not approved.
